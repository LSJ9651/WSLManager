## 1. 项目背景

WSLManager 是一款已完成的**便携式 WSL 发行版管理工具**（CLI 交互式菜单），现有文件：

| 文件 | 职责 |
|:-----|:-----|
| `WSLManager.bat` | 启动器：UTF-8 设置、UAC 自动提权、加载模块 |
| `WSLManager.psm1` | 核心模块（954 行）：新增/备份/还原/删除/配置 |
| `WSLManager_README.md` | 使用文档 |

现有能力：列出实例、新增发行版（微软商店 / 本地母版仓库 / 自定义 .tar 三种来源）、备份（自动清理旧备份）、还原（覆盖或新建）、删除（四级清理 + 输入名称二次确认）、配置管理（`Config/config.json`）。

**现有安全承诺**（代码已落实）：无网络访问、无注册表写入、无服务/计划任务、文件操作仅限 `WSLRoot` 目录树、删除二次确认。

**现状痛点**：仅 CLI 菜单，交互门槛高，不面向普通用户；新手看不懂术语（发行版、母版、.vhdx），误操作风险高。

---

## 2. 项目目标与范围

### 2.1 项目目标

为 WSLManager 提供一套 **GUI 图形界面**，让**零基础普通用户**也能安全、直观地完成 WSL 发行版的创建、备份、还原、删除等日常管理操作。

### 2.2 硬性要求（用户确认）

| 编号 | 要求 | 说明 |
|:-----|:-----|:-----|
| H-01 | 精致小巧不冗余 | 零安装、无额外运行时；不重写核心逻辑，复用现有代码 |
| H-02 | 界面美观现代化 | 现代视觉风格（圆角卡片、状态徽章、深浅主题） |
| H-03 | 少 bug | 复用已验证逻辑；统一错误处理；每步可验证 |
| H-04 | 后期可拓展 | 引擎层参数化，新增功能仅需"加引擎函数 + 加界面入口" |

### 2.3 非目标（本期不做）

- 不做 WSL 发行版内部的系统配置（如改 sources、装软件）
- 不做跨平台支持（仅 Windows）
- 不做移动端/远程管理
- 不扩展 `windows-scripting-guide` skill 的 WPF/XAML 规则

## 3. 用户画像与使用场景

### 3.1 目标用户

| 画像 | 特征 |
|:-----|:-----|
| 普通用户（主要） | 不了解"发行版/母版/.vhdx"等术语；只想要"我要装一个 Ubuntu"这样的操作 |
| 进阶用户（次要） | 熟悉 WSL，需要多实例、备份还原、数据目录管理等高级能力 |

### 3.2 典型使用场景

1. **首次使用**：安装工具后启动，界面引导检测 WSL 是否启用，未启用则引导 `wsl --install`
2. **创建系统**：通过三步向导从微软商店 / 本地母版 / .tar 文件创建新的 Linux 系统实例
3. **日常备份**：一键备份某个系统实例，可查看备份历史与磁盘占用
4. **还原系统**：系统出问题后，从备份时间线中选择备份恢复
5. **清理空间**：删除不再使用的实例，按需选择清理级别
6. **数据迁移**：配置数据根目录到非系统盘，查看各实例磁盘占用

## 4. 功能需求

### 4.1 功能总览

| 编号 | 功能模块 | 优先级 |
|:-----|:---------|:-------|
| FR-01 | 实例列表与状态展示 | P0 |
| FR-02 | 实例启动/停止 | P0 |
| FR-03 | 新增发行版向导（3 来源） | P0 |
| FR-04 | 备份发行版 | P0 |
| FR-05 | 还原发行版 | P0 |
| FR-06 | 删除发行版（4 级清理） | P0 |
| FR-07 | 设置（数据目录/默认版本/保留数） | P1 |
| FR-08 | 操作日志面板 | P1 |
| FR-09 | 首次启动引导 | P1 |
| FR-10 | 系统状态检测（WSL 可用性） | P1 |

### 4.2 详细需求

#### FR-01 实例列表与状态展示

- 主界面左侧展示所有已安装实例，每项包含：**实例名称、运行状态徽章（运行中/已停止）、WSL 版本、磁盘占用**
- 列表**自动定时刷新**（建议 5 秒间隔），也可手动刷新
- 底部常驻显示：**数据根目录路径** 与 **总磁盘占用**
- 右侧顶部统计卡片：磁盘占用总量、母版数量、备份数量

#### FR-02 实例启动/停止

- 选中实例后，右侧详情面板提供「启动」「停止」按钮
- 操作结果即时反馈（成功/失败），失败时给出可读原因

#### FR-03 新增发行版向导（3 来源）

- 采用**分步向导**（3 步），每步有明确说明：
  1. **选择来源**：微软商店在线安装 / 本地母版仓库 / 自定义 .tar 文件
  2. **选择具体项**：商店列表选发行版；仓库选母版；.tar 选文件（文件选择对话框）
  3. **确认**：实例命名（自动生成默认名）、WSL 版本（默认读配置）
- 全程展示**进度提示**（"正在下载安装…预计需要几分钟"）与当前步骤状态
- 名称冲突时友好提示并引导换名（对应现有 do-while 重试逻辑）
- 取消/失败时允许安全回退，不留下半成品实例

#### FR-04 备份发行版

- 选中实例后一键触发备份
- 展示**进度提示**（"正在导出约 X GB 数据，通常需要 1-3 分钟"），不使用假进度条
- 备份成功后提示：文件路径、文件大小
- 自动按保留数清理旧备份（沿用现有 `BackupRetentionCount` 配置）
- 磁盘空间不足 5GB 时警告并需确认

#### FR-05 还原发行版

- 以**备份时间线列表**展示（按时间倒序，含实例名、备份时间、大小）
- 还原方式二选一：**覆盖原实例** / **创建新实例**
- 覆盖前明确警告"原实例将被替换"
- 还原过程有进度提示与结果反馈

#### FR-06 删除发行版（4 级清理）

- **红色危险对话框**，展示将删除的影响范围（实例/备份/母版分别列出）
- 提供四级清理选择（沿用现有语义）：
  1. 仅注销实例（保留备份和母版）
  2. 注销 + 删除备份
  3. 注销 + 删除备份 + 删除母版
  4. 全量清理（含实例目录）
- **保留输入完整实例名二次确认**机制（安全承诺，不可移除）
- 任一步失败即中止后续清理，并报告失败原因（对应"防孤儿实例"规则）

#### FR-07 设置

| 设置项 | 说明 | 默认值 |
|:-------|:-----|:-------|
| 数据根目录（WSLRoot） | 可浏览选择；留空=工具所在目录；支持迁移到非系统盘 | 空（工具目录） |
| 默认 WSL 版本 | 新建实例默认 1 或 2 | 2 |
| 备份保留数 | 每实例最大备份数，0=不自动清理 | 5 |
| 临时文件清理天数 | 启动时清理 Temp 下超过 N 天的文件 | 3 |

- 设置修改后立即生效并写回 `Config/config.json`

#### FR-08 操作日志面板

- 主界面右侧底部展示操作日志（时间 + 动作 + 结果）
- 危险操作与失败操作醒目显示（颜色区分）
- 日志保留在会话内，可清空

#### FR-09 首次启动引导

- 首次运行显示欢迎页：说明工具用途、数据存放位置、安全承诺
- 检测 WSL 是否启用；未启用给出**一键引导**（`wsl --install`）与说明

#### FR-10 系统状态检测

- 启动时与运行中检测：`wsl.exe` 是否存在、WSL 内核版本、当前 WSLRoot 是否可写
- 不可用时给出中文可读提示与解决建议，不让用户看到原始错误

## 5. 非功能需求

| 编号 | 类别 | 需求 |
|:-----|:-----|:-----|
| NFR-01 | 兼容性 | 兼容 PowerShell 5.1（Windows 10/11 默认环境），不使用 PS 7+ 特性（`??`、`?:`、`-Parallel`） |
| NFR-02 | 编码 | 所有 `.ps1/.psm1` 文件：**UTF-8 with BOM + LF**；`.bat` 文件：**UTF-8 with BOM + CRLF**（参考项目 skill） |
| NFR-03 | 性能 | 界面操作流畅不卡顿；耗时操作（导出/导入）异步执行，UI 线程不阻塞 |
| NFR-04 | 安全 | 延续现有安全承诺：无网络、无注册表、无服务、文件仅操作 WSLRoot；删除需二次确认 |
| NFR-05 | 权限 | 主进程以普通权限运行；仅 `--unregister`/删除类操作通过提权子进程触发单次 UAC |
| NFR-06 | 健壮性 | 所有 `wsl.exe` 调用检查退出码（`$LASTEXITCODE`）；cmdlet 用 `$?`；失败必须中止后续破坏性步骤 |
| NFR-07 | 可用性 | 面向普通用户：术语大白话（发行版→"系统"）、大按钮、明确引导、错误信息可读 |
| NFR-08 | 可维护性 | 引擎层参数化、日志回调 + 返回结果对象；GUI 与 CLI 共用引擎逻辑，一处修改两处生效 |
| NFR-09 | 可拓展性 | 新增功能 = 引擎层加函数 + GUI 加入口；不修改架构骨架 |
| NFR-10 | 可移植性 | 全部文件收纳于工具目录，可整体复制移动（移动前备份的约束保留并提示） |

## 6. 界面设计需求

### 6.1 布局结构（主窗口）

```
┌────────────────────────────────────────────────────────┐
│ 标题栏                    [新增] [备份] [还原] [删除] [设置] │
├──────────────┬─────────────────────────────────────────┤
│ 实例列表      │ 统计卡片（磁盘占用/母版/备份）              │
│ 名称+状态徽章  ├─────────────────────────────────────────┤
│ WSL版本+大小  │ 实例详情（选中项）+ 启动/停止/立即备份       │
│              ├─────────────────────────────────────────┤
│ 数据目录      │ 操作日志面板                              │
└──────────────┴─────────────────────────────────────────┘
```

### 6.2 视觉风格

- 现代化扁平风格：圆角卡片、0.5px 细边框、充足留白（对齐 Windows 11 Fluent 语言）
- **深浅主题跟随系统**，浅色/深色均保证可读性
- 状态徽章配色：运行中=绿色、已停止=灰色、异常/危险=红色
- 危险操作按钮红色系，主操作按钮高对比
- 中文字体优先系统默认（微软雅黑/Segoe UI）

### 6.3 交互原则

1. **一键直达**：高频操作（备份、启动、停止）在主界面一个按钮完成
2. **向导化**：低频复杂操作（新增）走分步向导，每步只有一两个选择
3. **进度感知**：所有耗时操作必须有"预计时长"类提示，避免"卡死感"
4. **错误可读**：wsl 的英文 stderr 翻译成中文可读消息，附"查看详细日志"折叠区
5. **危险确认**：删除流程分级确认，最末一步输入实例名（安全承诺）

## 7. 权限与安全设计

| 场景 | 权限方案 |
|:-----|:---------|
| 浏览列表、查看详情、备份、启动/停止 | 主进程普通权限，无需提权 |
| 注销实例、删除实例、导入覆盖 | 提权子进程弹单次 UAC，仅执行具体命令 |
| 数据根目录在非管理员可写位置 | 正常权限即可 |

> 设计说明：不再沿用 CLI 版"启动即整体提权"的做法——GUI 高权限常驻会增加风险且反复 UAC 影响体验。

## 8. 技术方案与架构

### 8.1 总体架构（三层）

```
┌─────────────────────────────────────────────┐
│ GUI 前端层（WPF XAML）                        │
│ 实例列表 · 向导 · 进度 · 日志 · 设置           │
├─────────────────────────────────────────────┤
│ 核心引擎层（WSLManager.Engine.psm1）          │
│ 参数化函数 · 日志回调 · 结果对象               │
├─────────────────────────────────────────────┤
│ 系统层                                       │
│ wsl.exe · .vhdx 虚拟磁盘 · .tar 备份 · config.json │
└─────────────────────────────────────────────┘
```

### 8.2 文件结构（新增）

| 文件 | 职责 | 说明 |
|:-----|:-----|:-----|
| `WSLManager.psm1` | 现有 CLI 模块 | **保留不动**（CLI 能力不变） |
| `WSLManager.Engine.psm1` | 参数化引擎层 | 从现有模块提炼公共逻辑，GUI/CLI 共用 |
| `WSLManager.GUI.ps1` | WPF 主程序 | XAML 界面 + 事件处理 |
| `WSLManager.GUI.bat` | GUI 启动器 | 编码设置 + 加载引擎 + 启动界面 |

### 8.3 关键技术点

1. **引擎层设计**：参数化函数（实例名、目标目录、版本等作为入参）+ 脚本块日志回调 + 返回统一结果对象（成功/失败/消息/数据）
2. **NUL 字节处理**：`wsl -l -q` 输出解析沿用现有 `-replace '\0', ''` 安全模式
3. **异步执行**：`Runspace` / `Job` 异步执行耗时命令，UI 线程不阻塞，进度通过回调更新
4. **提权执行器**：独立提权进程执行 `--unregister` 等命令，主进程保持普通权限
5. **配置复用**：沿用 `Config/config.json` 与自愈重建逻辑
6. **错误翻译表**：维护 wsl 退出码/常见错误 → 中文可读消息映射

### 8.4 开发规范参考

- 参考项目 skill `windows-scripting-guide`（编码 BOM、PS 5.1 兼容、`$?` vs `$LASTEXITCODE`、WSL 命令安全流程、配置自愈、破坏性操作七步序列）
- skill 仅约束引擎层 CLI 逻辑；GUI 层（WPF/XAML）不受其约束

## 9. 验收标准

### 9.1 功能验收

| 编号 | 验收项 | 通过标准 |
|:-----|:-------|:---------|
| AC-01 | 实例列表 | 能正确显示所有实例名称/状态/版本/大小，无乱码、无空行 |
| AC-02 | 新增向导 | 三种来源均可走完创建流程，名称冲突时正确拦截 |
| AC-03 | 备份 | 备份成功生成 tar，超保留数时自动清理最旧备份 |
| AC-04 | 还原 | 覆盖/新建两种方式均能恢复，覆盖前有明确警告 |
| AC-05 | 删除 | 四级清理行为与 CLI 版一致；输入错误名称无法删除 |
| AC-06 | 设置 | 四项配置修改后写回 config.json 并立即生效 |
| AC-07 | 权限 | 普通操作不弹 UAC；删除类操作仅弹一次 UAC |

### 9.2 质量验收

| 编号 | 验收项 | 通过标准 |
|:-----|:-------|:---------|
| AC-08 | 编码规范 | 所有新增文件通过 BOM/换行符检查（xxd 验证 UTF-8 BOM） |
| AC-09 | 语法校验 | 所有 `.psm1/.ps1` 通过 PowerShell Parser 检查，0 错误 |
| AC-10 | 行为一致 | GUI 与 CLI 对同一操作输出结果一致（对比测试） |
| AC-11 | 不卡界面 | 备份/还原期间界面可操作、有进度提示 |
| AC-12 | 便携性 | 整个目录复制到新机器后可正常运行 |

## 11. 术语表（面向普通用户的用语映射）

| 术语（技术） | 界面用语（大白话） |
|:-------------|:-------------------|
| 发行版（Distribution） | 系统 |
| 实例（Instance） | 一个安装好的系统 |
| 母版（Repository/Template） | 系统模板（可复制出多个系统） |
| 备份（Backup） | 系统快照/存档 |
| 还原（Restore） | 从存档恢复系统 |
| 注销（Unregister） | 移除系统记录 |
| WSLRoot | 数据存放位置 |
| 虚拟磁盘（.vhdx） | 系统的硬盘文件 |
