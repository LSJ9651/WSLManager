# WSL 发行版管理工具

一个用于管理 WSL（Windows Subsystem for Linux）发行版的 PowerShell 工具，通过交互式命令行菜单完成新增、备份、还原、删除等操作。

## 功能特性

- **列出发行版**：显示所有已安装的 WSL 发行版及其运行状态
- **新增发行版**：支持从微软商店下载、本地母版仓库、自定义 .tar 文件三种方式
- **备份发行版**：将发行版导出为 .tar 文件（命名规则 `full_YYYYMMDD_HHmmss.tar`），备份前自动检测磁盘空间，并支持按保留数量自动清理旧备份
- **还原发行版**：从备份文件还原，支持覆盖原实例（先停止、注销再导入，注销失败即中止）或创建新实例
- **删除发行版**：带二次确认机制，提供四级清理选项（仅注销 / 删除备份 / 删除母版 / 全量清理）
- **完全可移植**：整个文件夹可随意移动，脚本自动适配位置。注意：若 `Instances\` 下存在已注册的实例，直接移动文件夹会导致实例注册路径失效而无法启动；移动前请先用"备份发行版"功能导出 .tar 备份（或确认已有备份），移动后通过"还原发行版"重建实例
- **自包含管理**：所有 WSL 相关文件默认存放在脚本目录下，也可通过 `WSLRoot` 配置迁移到其他盘符或路径

## 目录结构

```
WSLManager\
├── WSLManager.bat          # 双击启动入口
├── WSLManager.psm1         # 核心功能模块
├── README.md               # 使用说明文档
├── Config\
│   └── config.json         # 用户配置文件
├── Repositories\           # 母版仓库（.tar 压缩包）
├── Instances\              # 运行实例（.vhdx 文件）
├── Backups\                # 备份存档
└── Temp\                   # 临时工作区
```

## 使用方法
1. 将 WSLManager 整个文件夹解压/复制到任意位置（任意盘符、任意路径均可，建议使用英文路径）
2. 双击 `WSLManager.bat` 启动工具，首次运行会自动创建 Config/、Repositories/、Instances/、Backups/、Temp/ 目录
3. 工具会自动请求管理员权限
4. 在菜单中选择相应功能进行操作

## 功能说明

### 新增发行版（三种来源）
- **从微软在线商店下载**：输入发行版名称后自动完成"安装 → 导出为母版 → 注销默认实例 → 导入到托管位置"全流程，创建成功即母版入库，后续可随时复制出新实例
- **从本地母版仓库创建**：从 `Repositories\` 中已有母版创建新实例
- **从自定义 .tar 文件导入**：指定本地 .tar 文件，自动复制为母版并创建实例

新增实例时会自动检查实例名是否已存在。默认实例名：在线商店来源使用发行版名；母版/自定义来源自动生成为 `<名称>_YYYYMMDD`。

### 备份发行版
- 从已安装实例中选择一个，导出为 .tar 文件，存放在 `Backups\<实例名>\` 下
- 备份前自动检测磁盘空间：若可用空间不足 5GB，会发出警告并询问是否继续
- 备份成功后显示文件路径和大小，并按 `BackupRetentionCount` 自动清理该实例的旧备份（0 = 不自动清理）

### 还原发行版（两种方式）
- **覆盖原实例**：先停止并注销原实例（注销失败会中止操作），再从备份导入
- **创建新实例**：保留原实例，用备份创建另一个新实例

### 删除发行版（四级清理，需输入实例完整名称二次确认）
1. 仅注销 WSL 实例（保留备份和母版）
2. 注销 + 删除该实例的备份
3. 注销 + 删除备份 + 删除母版
4. 全量清理（删除所有相关文件）

## 配置说明

首次启动时会自动创建 `Config\config.json`，包含以下配置项：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| WSLRoot | WSL 根目录路径（留空则使用脚本所在目录） | 空 |
| DefaultWSLVersion | 默认 WSL 版本（1 或 2） | 2 |
| AutoCleanTempDays | 自动清理超过 N 天的临时文件（启动时执行） | 3 |
| BackupRetentionCount | 每个实例保留的最新备份数量（0 = 不自动清理） | 5 |

## 兼容性

- Windows 10（版本 2004+）/ Windows 11
- PowerShell 5.1
- 同时支持 WSL 1 和 WSL 2

## 注意事项

- 需要管理员权限运行（脚本会自动请求）
- 删除操作不可恢复，请谨慎操作
- 备份文件默认保留最新的 5 个，可在配置中调整（设为 0 则不自动清理）
- 若磁盘可用空间不足 5GB，备份前会发出警告并询问是否继续
- 配置 `WSLRoot` 后，Repositories/、Instances/、Backups/、Temp/ 会创建在该目录下而非脚本目录
